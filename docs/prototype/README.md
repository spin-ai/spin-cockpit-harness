# 页面优化原型

三个可直接打开的静态原型，用来说明「资料 / 记忆 / 人物」三页应该怎么排。不是最终实现，但每个改动都对应一处具体问题。

打开方式：双击对应 HTML（无构建、无依赖）。右上 `◐` 切亮 / 暗。

| 文件 | 页面 | 主要解决的问题 |
|---|---|---|
| [`knowledge.html`](knowledge.html) | 资料（知识库） | 输入与输出被拆到两列；引用点不动；解析引擎配置占满右栏；看不到解析质量 |
| [`memory.html`](memory.html) | 记忆 | L1–L4 是内部词汇；复核队列被压在正文下；主 CTA 是「运行 Dream」；注入预览只读 |
| [`persona.html`](persona.html) | 人物（人物建模） | 只有陈述性事实，没有性格与处事；没有单一可读的人设卡；关系网与置信度缺位 |

## 三页共同的结构

```
左：导航 / 列表（常驻，选择不销毁上下文）
中：唯一主 surface（当前对象 + 证据）
右：复核队列置顶 → 变化 / 注入 → 辅助操作
```

这样三页学一次就够：左栏选对象，中间看内容，右栏处理「需要人判断」的事。

## 每个原型的可点交互

**资料**

- 点引用角标 `1` / `2` → 右栏对应出处高亮，可打开原页
- 点左栏资料 → 中栏切换成解析预览（页码 / 片段 / 未识别页标黄）
- 展开 `配置 / 注册自研引擎` → 端点、密钥、超时
- 勾选框控制「参与检索」的资料范围

**记忆**

- 切层级（结论 / 项目 / 事实 / 原始）→ 标题、说明、条目一起换
- `未验证观察` / `Dream 建议` 两个 tab；接受 / 拒绝后计数同步下降
- 点注入预览里的条目 → 展开「为什么被裁」
- 条目 `⋯` → 查看来源与引用 / 编辑 / 降级 / 标为过期

**人物**

- 点人物 → 换人设卡；没有卡的人给真实空态（待确认 N 条 → 去确认）
- 每节 `展开原话` → quote / 时间 / 来源
- 复核队列接受 / 拒绝后，页头与列表角标同步下降
- 人物 `⋯` → 复制注入片段 / 导出角色卡 JSON / 删除

## 设计约束

- 颜色、圆角、阴影全部取 `src/design-system.css` 的 token，没有一次性色值
- 一个区域最多一个 primary；低频操作进 `⋯`
- 中文正文 ≥ 11.5px，10–10.5px 只用于时间、编号、状态
- 亮色 / 暗色同构，不靠单边补丁
