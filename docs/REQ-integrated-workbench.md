# REQ · 场景工作台（原始记录）

> 一条一条记录原始需求，不解读、不展开。确认后再补数据模型、交互和排期。
> 关联：Mission / TODO / Terminal / Chat。

## 1. 原始需求

1. 把「所有项目 + 项目内终端」收在一个场景配置页面里。
2. 场景配置针对所有打开的项目，以及项目内部打开的终端。
3. 场景配置用文字即可修改。
4. 场景配置要能管理所有进展。
5. 在 Chat 里聊好天，确认可以执行。
6. 根据场景配置自动分配任务。
7. Chat 可以随时查看所有进展。
8. TODO 应该是能够看到所有项目、所有终端的执行状态的。
9. 打开一个项目，进入终端，直接起一个 pi agent，运行跑了一段时间，想看下进行的状态，要能有一个统一的地方看。
10. 我有一个针对这个项目的任务，需要项目里面有多个 Agent 同时跑。
11. 希望是开了 terminal 后再打开 pi agent 跑的方式，而不是我看不到的 agent 在执行。
12. Mission 是任务的一种，不单独做一套页面。
13. TODO 是任务列表 / 看板，Mission 也在里面。
14. Terminal 是 Agent 实际运行的地方，任务和终端要能互相对应。
15. 场景配置决定任务怎么分配、用哪个 Agent、怎么跑。
16. Chat 是入口，也是查看所有进展的地方。
