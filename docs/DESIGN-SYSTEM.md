# Design System

> 状态：v1 · 2026-11  
> 来源：`src/design-system.css` + `src/components/PageHeader.tsx` + `src/components/EmptyState.tsx`  
> 参考：ORCA 的克制、中性色、alpha 边框和紧凑 pane chrome；不是复制视觉，而是借用约束。

## 1. 设计原则

1. **安静优先**：默认界面不靠高饱和色、粗边框、重阴影制造层级。
2. **一个主面**：页面是 canvas + 一个主 surface；模块是主面内部的分节，不是层层卡片。
3. **颜色有语义**：主色只负责选中 / 主操作；绿、黄、红只负责状态。
4. **尺寸有系统**：字号、间距、圆角、阴影都从 token 取，不按页面临时决定。
5. **操作有主次**：一个区域最多一个 primary；低频操作收进 `⋯`。
6. **可读性优先**：中文正文不小于 11.5px；小字只用于状态、时间、快捷键。
7. **亮暗同构**：亮色和暗色使用同一套结构，不靠硬编码颜色互相打补丁。
8. **一个区域一行 chrome**：标签栏 / 页头二选一，不在它上面再叠一条工具栏；常驻位置只放「当前对象 + 主操作」，其余进菜单 / 右键 / 快捷键（见 §5「一行 chrome」）。

## 2. 单一事实来源

| 内容 | 位置 |
|---|---|
| 字体、表面、边框、圆角、阴影、默认亮暗色 | `src/design-system.css` |
| 一级页面页头 | `src/components/PageHeader.tsx` |
| 空态 | `src/components/EmptyState.tsx` |
| 全局布局 / 组件样式 | `src/styles.css` |

不要在其他文件里新增 `#xxxxxx`、`12px` 圆角这类一次性值。

## 3. Tokens

### 字体

```css
--font-sans: "Geist Variable", "Geist", -apple-system, "PingFang SC", ...;
--mono: "Geist Mono Variable", "Geist Mono", "SF Mono", ...;
```

- UI：Geist Variable；中文回退 PingFang SC / Microsoft YaHei
- 代码、ID、终端、路径：Geist Mono
- 基础字号 13px / 1.55
- 中文正文最低 11.5px；辅助信息最低 10.5px

### 字号

| 用途 | 大小 |
|---|---|
| 一级页面标题 | 22px / 600 |
| 区块标题 | 12.5–13px / 600 |
| 正文 | 13px |
| 次要正文 | 12px |
| 辅助信息 | 11–11.5px |
| Kicker / 表头 | 10–11px，大写 + letter-spacing |

不要用 9px 承载中文说明。

### 间距

```text
4 / 8 / 12 / 16 / 24 / 32
```

- 行内 gap：4–8
- 控件间距：8
- 区块内部：12–16
- 区块之间：16–24
- 页面级别：24–32

### 圆角

```css
--radius: 10px;        /* 主面 */
--radius-sm: 6px;      /* 小控件 */
--radius-lg: 14px;     /* 浮层 / 大面 */
```

不要再新增 7 / 9 / 11 / 12 / 13 / 16 等一次性圆角。

### 阴影

```css
--shadow-1: 0 1px 2px rgba(10,10,10,.045);
--shadow-2: 0 10px 24px rgba(0,0,0,.16);
--shadow-float: 0 18px 46px rgba(0,0,0,.22), 0 2px 8px rgba(0,0,0,.10);
```

- surface：优先靠背景和 hairline，不靠阴影
- 浮层：`--shadow-float`
- 不要为每个卡片写独立 shadow

### 表面与边框

亮色（默认 light）：

```css
--page-canvas:#fafafa; --surface:#ffffff; --surface-hover:#f5f5f5;
--sidebar:#fafafa; --border:#e5e5e5; --border-strong:#d4d4d4;
--fg:#0a0a0a; --fg-2:#404040; --muted:#696969; --faint:#a3a3a3;
--brand:#171717; --brand-soft:#f2f2f2;
```

暗色（默认 dark）：

```css
--page-canvas:#0a0a0a; --surface:#171717; --surface-hover:#262626;
--sidebar:#111111; --border:rgba(255,255,255,.08);
--border-strong:rgba(255,255,255,.14);
--fg:#f0f0f0; --fg-2:#d4d4d4; --muted:#a3a3a3; --faint:#737373;
--brand:#e5e5e5; --brand-soft:#262626;
```

规则：

- 暗色边框用 **alpha 白**，不是实色灰
- 主色默认中性；蓝、紫、橙只做语义强调
- 其他主题（paper / midnight / forest / …）继续使用自己的 palette，不被默认主题覆盖

## 4. 页面结构

```text
Page
├─ PageHeader        标题 / 副标题 / 主操作 / 可选 tabs
├─ Main surface      一个主面（Surface 三档之一）
│  ├─ Section        用留白和字号分节
│  └─ Row / List     行分隔用极淡 hairline
└─ EmptyState        整块空态；内联空态用 .inline-empty
```

### 4.1 三种外壳（只能选一种）

| 外壳 | 用于 | 宽度 | 页面 padding | 滚动 |
|---|---|---|---|---|
| **标准页** `.wide > .page` | 项目 / 统计 / 主机 / Git / 机器人 / 视觉 | `max-width:1280` | 24 / 24 / 32 | `.wide` 滚 |
| **全宽工作台** | 知识库 / 记忆 / 人物 / 设置 | 不限宽；设置正文 `max-width:880` | 16 / 24 / 16 | 页面内部滚 |
| **舞台** | 场景 | 不限宽 | 12 / 16 / 16 | 满高，内部自己缩放 |

- **不允许第四种外壳**：页面里不再写 `max-width:1320/1180/1440` 或自己的左右 padding。
- **左侧留白统一**：所有外壳左边距都取 `--page-gutter`（24px；≤1100px 时 16px）。`.wide > .page` 左对齐（`margin:0`），不用 `margin:auto` 居中；内容限宽只影响右侧。
- 阅读页（说明 / 项目 Wiki）是标准页的变体：`max-width:1180`，标题可用 24px，其余同标准页。
- 一级页面 1280 是上限，不是目标；内容窄时保持单列阅读宽度。

### 4.2 PageHeader

- 所有一级页面必须用 `PageHeader`；例外只有阅读页（见 4.1）。
- **标题单语**：中文模式只显示中文标题，不再叠加英文 kicker；接入英文语言时标题 / 导航整体切换，不混排（不做「英文小字 + 中文大字」）。
- 语言设置：设置 → 外观 → 界面语言（中文 / English）。英文模式当前只翻译 chrome（标题 / 导航 / 页签 / 页头按钮 / 设置导航与按钮），正文和用户内容保持原语言。
- 标题 = 页面名；分区名放 tabs / 左导航，不占 h1。唯一例外：设置页 h1 = 当前分区（页面名由左导航承担）。
- 标题字号固定 **22 / 600**（阅读页 24）；页面内不得再写 `h1/h2` 或覆盖标题字号。
- 标题只放页面名：不加编号、状态、英文小字；状态进副标题或 tabs。
- 副标题二选一：短字符串，或 `<div class="stat-strip">` 统计块（最多 5 项）。
- 页头动作最多一个 primary；返回一律 `ChevronLeftIcon`，不写「←」。
- 页头动作高度 26px；`PageHeader` 的 `actions` 不再各自改高度。

### 4.3 Tabs 与 Segmented

- **页面级切换**用 `Tabs`（胶囊，放 `PageHeader.tabs`）；**视图切换**（卡片 / 列表）用 `Segmented`（放 `PageHeader.actions`）。
- 笔记 / 知识库里的**文档标签**是第三种，只能用 `.notes-tabs`，不算页面级 tab。
- 统一外观：容器 surface + hairline、`radius 6`、高 26px、选中 surface + `shadow-1`。
- 禁止：标题上方再浮一条 tab；同一页面出现两种页面级 tab 外观；下划线 tab（存量 `.off-tabs` 收敛）。

### 4.4 Surface 三档

| 档 | radius | 用途 | 边框 / 阴影 |
|---|---|---|---|
| **surface（panel）** | 10 | 页面主面 / 面板 | hairline 或 `shadow-1`，二选一 |
| **float** | 14 | 抽屉 / 模态 / 浮层 | `shadow-float` |
| **tile** | 10 | 统计 / 概览小块 | hairline + `shadow-1`，不要左侧色条 |

- 一个页面一个主 surface；其余是分节，不是卡片套卡片。
- **不得新增卡片体系**（`.xxx-card`）；需要卡片时用 `.panel`。
- 禁止 radius 7 / 9 / 11 / 12 / 13 / 16；统计 tile 也统一 10。
- 舞台插画内部（`.off-*` 画布元素）不受这条约束；它们不是 UI surface。
- **唯一例外：Chat 窗口**（`.chat-pane` / `.bot-main` 内的 `.ds-*`）。它整体照搬 deepseek-harness 的会话界面，用户气泡用 `--radius-chat-bubble`（20）、composer 用 `--radius-chat-composer`（28）；代码卡仍是 10。除这两个值外不得再引入新的圆角，细节见 [`arch/ARCH-chat-ui.md`](arch/ARCH-chat-ui.md)。

### 4.5 左栏与列宽

| 场景 | 宽度 |
|---|---|
| 工作台列表栏（知识库 / 记忆 / 人物 / 笔记） | 232 |
| 设置左导航 | 218 |
| TODO | 360（可拖 240–560） |
| 终端页左栏上下两段 | 列宽同上（任务・项目）；上段 Chat 高 320（可拖 140–900），下段任务列表吃剩余 |
| 终端页左栏三段折叠 | Chat / 任务 / 项目 各自行尾 chevron；折叠只收内容、段头留原位（Chat 40px，任务 / 项目 各一行） |
| 终端页右栏 | 默认收起（34px 窄条），要浏览文件 / 会话 / Git 时再展开；终端主面吃满剩余宽度 |
| 场景 inspector | 300–320 |
| 右侧 meta 栏 | 264–306 |

列宽写在页面外壳里，不在组件里写死。

### 4.6 空态

- **整块空**：`EmptyState`（面板里用 `compact`）。
- **内联空**：`.inline-empty`（11.5–12px、左对齐、无图标、无背景）。
- 不新增空态类；`.pane-empty` / `.notes-meta-empty` / `.bot-empty` / `.git-page-empty` 都是收敛对象。

### 4.7 概览条

- 实体计数用 `.overview`（项目 / 主机 / 机器人同一套）。
- 指标用 stats tile；舞台内用 scene-stats。
- 不新增第四种概览样式。

## 5. 组件规则

### 按钮

- 一个区域最多一个 `.btn.primary`
- 页面操作、行操作默认 ghost/outline
- 低频操作进 `row-menu`（`⋯`）
- 高度：30px；小按钮 26px，**唯一类是 `.btn.tiny`**（`.btn.tiny-btn` 只做别名迁移，不再新增）
- 页头动作 26px；`.settings-body` 等外壳不再单独覆盖按钮高度
- 不使用多个同权重按钮并排表达主次

### 一行 chrome（区域头 / 工具栏）

一个区域**只留一行** chrome：标签栏、页头、pane head 三选一，不在它上面再叠一条工具栏。
终端区就是反例改成的正例：原来「工具栏 40px（品牌字 + 视图切换 + 打开项目 + 查找 + 快捷命令 + 字号 + 新建）+ 标签栏 34px」，
砍成一行 34px 后省 37px，能做的事一个没少。

- **常驻位置只放两样**：当前对象（标签 / 标题）+ 主操作。其余进 `＋` 菜单、右键菜单或快捷键
- **一个动作只有一个常驻入口**：新建、查找、快捷命令、字号复位、窗格控制在菜单 / 右键 / 快捷键里；出现第二处就合并，不允许并存
- **进常驻前先答一个判据**：删掉它，用户是否要多点**两次以上**才能做完同一件事？不是 → 不许常驻
  （反例均不合格：查找有 `⌘F`；快捷命令有右键；字号复位有 `⌘0`；打开项目有左栏「项目 → 添加」）
- **动态信息按需出现**：终端识别到的 `:PORT`、可接入的 `#KEY` 只在条件成立时以窄 chip 出现，不占常驻位
- **不写区域品牌字**：`Terminal` / `Chat` 这类名字由导航和标签承担，区域头里再写一遍就是冗余
- **菜单是入口不是垃圾桶**：`＋` 菜单用分组标题（`.term-menu-head`）分「新建 / 起 Agent」，条目 ≤ 8；超了说明该拆，不是缩字号

参考实现：`.term-strip` + `.term-strip-actions`（`src/components/TerminalPanel.tsx`）。

### 图标行（icon cluster）

一行里并排的**纯图标按钮**（区域头、工具栏、卡片行尾）按同一套尺寸排：

| 项 | 值 | 说明 |
|---|---|---|
| 点击区 | **20px**（`--icon-size`） | 13px 字形居中；不再出现 22 / 24 / 26 混排 |
| 按钮间缝 | **1–2px**（`--icon-gap`） | 靠 hover 底色区分边界，不靠留白 |
| 字形 | **15px**（见下表；微图标 / rail 例外） | 用 `Icons` 组件；**`＋ / −` 一律 `PlusIcon` / `MinusIcon`，不写字符** |
| 对齐 | 文字在左、图标组**靠右**（`margin-left:auto` 或 `.spacer`） | 组内不再夹文字 |
| 数量 | 一行 ≤ 4 个 | 第 5 个起进 `RowMenu (⋯)` / `＋` 菜单 |
| 混排 | 同一行里「新建 / 最大化 / 收起」字号和点击区**一样大** | 不允许 18+22+22 这种混排 |

字形只有三档，不许再出现第四种（**页头、工具栏、标签页、文件树必须同一号：15px**）：

| 场景 | 字形 | 点击区 | 例子 |
|---|---|---|---|
| **界面图标**：页头 / 工具栏 / 标签页 / 文件树 | **15px** | 20px（标签页 30–36） | `⌄ ⤢ ⤡ ＋ ⋯ ⚙︎`、文件夹、文件、右栏 文件 / Git / 会话 |
| 行内微图标（时间、状态、段落 chevron） | 11–12px | — | `.tree-chev`、`.msg-time` 旁 |
| 主导航 rail | 19px | 48px | 左侧 rail |

> 2026-11-22 修正：先前分成「动作 13 / 内容 14 / 标签页 15」三档，并排看会一大一小（任务栏比右栏小一圈），已统一成 15。
> 尺寸写死在 `styles.css` 的一条选择器组里，不靠每个调用点传 `size`。
| 状态 | `title` + `aria-label`，开合类同步 `aria-expanded` / `aria-pressed` | 与「开合控件」一节一致 |

**反例（已改）**：项目面板头原来「＋ 添加 / 管理」是两条文字链 + 22px 图标混排，`.spacer` 在面板里根本没定义，
图标贴在标题后面；现在统一成 `⌄ 项目 … ⚙︎ ＋ ⋯`，20px 点击区、2px 缝、靠右成组（实测间距 21px）。

参考实现：`.project-panel-actions`（项目面板）、`.explorer-actions`（资源管理器）、`.term-strip-actions`（终端）。

### 计数与徽标（数字）

数字只回答「有多少」，**不负责装饰**。不要因为手边有个 `length` 就往标题、图标、标签后面挂一个数。

| 位置 | 允许 | 例子 |
|---|---|---|
| 列表行 / 分组行尾 | ✓ | `.session-group-head`、`.notes-folder-label`、`暂存的改动 3` |
| 概览条 / 统计 / 筛选结果 | ✓ | `.overview`、`3 个协作场景`、`2 / 12` |
| 区块内容头（列表就在它下面） | ✓ 至多一次 | `待处理 3`、`分配到的任务 2` |
| 标签页（tab） | ✗ | 会话历史 tab 上曾挂的 `5`（已下线） |
| 图标旁 / 图标行 | ✗ | `⧉ 5`、图标角上的红点 |
| 区域头 / 页头标题 / 导航项 | ✗ | `智能体会话 5`、`终端 2` |

规则：

- **导航不放数据**：总数属于列表和概览，不属于 tab / 图标 / 标题。列表已经分组计数时，头上再写一遍是重复。
- **一个数只出现一次**：列表已能读到就不要再挂到别处（会话历史 tab 的 `5` 和面板头的 `5` 同时存在，删完一处信息一点没少）。
- **只有「需要你处理」才配出现在 chrome 上**，且 `>0` 才渲染、`0` 一律不渲染（不显示 `0` 占位）。
- **要处理也进内容区**：`待处理 3` 写在待处理面板自己的标题行，不写成 tab 上的角标。
- **计数是文字，不是徽标**：10.5–11px、`--faint` / `--muted`，不用彩色 pill、徽标球、红点、round badge。
- **`title` / `aria-label` 不拿数字凑数**：`会话历史` 就是 `会话历史`，不要 `会话历史（5）`，数字读屏时会变成噪音。

旧类 `.tab-count` / `.tab-count-inline` / `.icon-tab-count` / `.bot-tab-count` 已下线，`npm run verify:design` 会拦。

### 开合控件（打开 / 关闭 / 展开 / 收起）

**一条规则：能用图标表达的，不写文字。** 凡是「打开 / 关闭 / 展开 / 收起」，
一律用图标 + `title` / `aria-label`；文字只留给「新增 / 管理 / 跳转 / 保存」这类动作。

| 场景 | 控件 | 图标 | 尺寸 / 类 |
|---|---|---|---|
| 窗格收起 / 最大化 / 还原 | `PanelCollapse` / `PanelExpand` / `PanelRestore` | 13px | `.pane-collapse`（20px，同图标行） |
| 段落折叠（TODO / 机器人 / 项目、树、思考、工具、进展） | `ChevronDown`，**放在行尾**，展开时 `rot-180` | 11–13px | `.pane-fold` / `.icon-btn` / 行内 |
| 面板 / 抽屉 / 弹层 / 预览关闭 | `XIcon` | 12–13px | `.icon-btn`（22px）/ `.off-icon-btn`（28px） |
| 详情 / 检查器开关 | `Eye` / `EyeOff` | 13px | `.btn.tiny` + `.on` |
| 场景 / 面板配置 | `Wrench` | 13px | `.btn.tiny.ghost` |
| 低频操作 | `Ellipsis` | — | `RowMenu` |

补充规则：

- 不再用 `×` / `✕` 字符当关闭按钮；一律 `XIcon`
- 不再写「收起 / 展开 / 关闭」三个字；折叠方向由 chevron 表达
- 同一段头只能有一个折叠开关（标题文字不再兼作按钮）
- 所有纯图标按钮必须有 `title` + `aria-label`（`aria-expanded` / `aria-pressed` 跟状态同步）
- 内容级展开保留一个名词（`原话` / `全文` / `输出` / `进展`），但动词用图标表达

- 左栏三段（Chat / 任务 / 项目）各自行尾一个 chevron：**折叠只收内容，段头留在原位**（Chat 收起成 40px 段头，任务 / 项目收起成一行）；
  收起任务段时腾出的高度先给展开的项目列表，项目也收起时再给 Chat，不留大片空白。

### 列表稳定性（点击不得重排 / 跳动）

- 排序默认「固定」（沿用原有顺序）；`最近活动`、`按名称` 只是可选，且不能是默认。
- 选中 / 激活某一行**不改变**：列表顺序、展开状态、滚动位置。
- 展开只由行内 chevron（`ChevronDown`）触发；"它变成了当前项目"不是展开理由。
- `scrollIntoView` 只出现在显式跳转（打开某个任务 / 会话），不进列表点击路径。

### 行内操作菜单

- 低频操作使用 `RowMenu`，不要继续堆按钮
- 点击外部、Esc、滚动、窗口 resize 时关闭
- 菜单用 portal + fixed 定位，避免被 `.wide` / 列表滚动容器裁切
- 靠近视口底部时向上展开
- 执行菜单动作后关闭

### 页头副标题

- 最多两行
- 超出用 ellipsis，并设置 `title` 保留完整文本
- 不要用 `white-space:nowrap` 把说明截成一行

### 工作区焦点

- 非当前 pane 不整体降低透明度
- 只弱化 pane header / toolbar
- 内容区域保持可读性

### 列表

- 行内主信息一行，元信息第二行
- 失败 / 运行列表使用固定列网格
- 状态、时间、耗时右对齐
- 长文本必须 `ellipsis` + title
- 行 hover 显示操作，不要默认铺满按钮

### 字号阶梯

只用这几档，不要临时加 9.5 / 10.5 / 11 / 11.5 之外的值（2026-11 全量上调过一档，因为 9–11px 占了大半，整体观感偏小）：

| 用途 | 字号 |
|---|---|
| 页面标题 | `--text-title`（22px） |
| 正文 / 段落 / 对话 | 13.5px |
| 列表主行 / 表格正文 | 12.5px |
| 次级信息（说明、行副标题） | 12px |
| 元信息（时间、来源、计数） | 11.5px |
| 辅助（快捷键、单位、徽标） | 10.5–11px |

- 中文正文（任何超过 4 个字的句子）不小于 11.5px；10.5px 只放时间/快捷键/计数这类「看一眼就走」的信息
- 想整体放大不改字号：设置 → 外观 → 界面缩放（`uiScale`，默认自动跟随屏幕分辨率）
- 终端字号独立（`terminalFontSize`），不跟这里的阶梯走

### 状态

| 语义 | 颜色 |
|---|---|
| 成功 / 完成 | green |
| 等待 / 风险 | amber |
| 失败 / 危险 | red |
| 运行 / 选中 | neutral primary（必要时蓝） |
| AI 动作 | 紫色，少量 |

不要用同一种蓝色同时表示“选中、运行、成功、链接”。

### 空态

整块空统一使用 `EmptyState`：

- 一个短标题
- 一句解释
- 最多一个下一步操作
- 不用一整屏空白 + 一行灰字

内联空（列表为空的一句话提示）用 `.inline-empty`，不要再造 `notes-meta-empty` 这类新类。

### 反馈：toast 与报错

| 用什么 | 适合什么 | 行为 |
|---|---|---|
| `toast`（`.toast`，底部居中） | 成功 / 已完成的轻提示 | 3 秒自动消失，只放「已保存」「已复制」这类无需回看的信息 |
| 报错卡（`.errstack` / `.errcard`，右下角） | 失败 / 异常 / 需要人工处理 | **永不自动消失**，带时间 + 动作名 + 「复制」，最多堆 5 条，手动关 |

- 报错必须能读到全文（`pre` + `pre-wrap` + 滚动），**不用 ellipsis 截断**，否则用户拿不到定位信息
- 报错不要和成功提示抢同一个槽位：后者会 3 秒后把前者顶掉，看起来就是「一闪而过」
- 同一动作的同一句话 10 秒内只堆一条（轮询失败不会刷屏），并用时间戳更新
- 统一走 `src/App.tsx` 的 `act()`：IPC 抛错 → `notifyError(action, err)`，去掉 `Error invoking remote method '…'` 前缀后再展示

## 5.5 高亮 / 聚焦 / 闪烁

高亮只用于“当前位置”，不用于装饰。禁止整块发光。

| 场景 | 正确做法 |
|---|---|
| 文本选中 | `fg` 14% alpha 背景，文字颜色不变 |
| 富文本编辑器聚焦 | 1px `border-strong` + `shadow-1`，不要 3px ring |
| 输入框聚焦 | 2px ring，最多 `border-strong` |
| 搜索定位 / TOC 跳转 | 8% `fg` 背景，0.8s 内淡出 |
| 可视化 HTML | 1px `border-strong`，不要蓝色虚线 |
| CodeMirror 选中 | 14% `fg`，不要 22% brand |
| 行内代码 | 5% `fg` 背景，不要像标签一样亮 |

禁止：

- 整个编辑器 / 面板套 `box-shadow: var(--ring)`
- 搜索命中闪蓝光
- 选中文字使用高饱和蓝或高不透明度 brand
- 同时叠加 border + ring + background 三种高亮

## 6. 动效

- 背景 / 边框 / 颜色：120–160ms
- 浮层：160–200ms
- 不做大面积位移、弹跳、无限呼吸
- 尊重 `prefers-reduced-motion`

## 6.5 缩放与窄视口

- 整窗缩放 80–150%（`⌘+` / `⌘-` / `⌘0`，设置 → 外观），作用于 `webContents.setZoomFactor`；
  终端聚焦时这组键仍归终端字号。
- 缩放会让 CSS 视口变小，所以布局必须能在 ~720px 宽度下工作：
  - 不要给 `body` / 根容器设大 `min-width`（窗口本身有 `minWidth`）；
  - 固定宽度的侧栏用 `minmax(保底, 目标宽)`，并按可用宽度等比收缩；
  - 面板头/工具条里能省的字（计数、次要链接、提示）在 `≤1080px` / `≤900px` 隐藏，不要让中文挤成竖排；
  - 用 `@container` 处理面板内部的宽窄（composer、终端、预览面板、任务详情 `.task-detail` 已经是容器）；
  - 详情类页面默认**单列**，只有容器 ≥760px 才上右侧信息栏——终端区常态 300–600px，用窗口 `@media` 判断宽度会永远走「宽屏」分支，表格被挤到看不清。

## 7. 可访问性

- 正文对比度 ≥ 4.5:1
- 小字不使用 `--faint` 承载关键信息
- `--faint` 也要过 4.5:1（2026-11 修）：亮色 `#a3a3a3` 只有 2.52:1，已改为
  `light #6f6f6f` / `paper #6c6659` / `vslight #6f6f6f`；`--muted` 同步加深保持层次。
  新增主题时按 `npm run verify:design` 之外再自查一次对比度
- focus-visible 必须可见
- 图标按钮必须有 title / aria-label
- 不用颜色作为唯一状态信号

## 8. 禁止模式

以下写法不再接受：

- 页面内新增 `#xxxxxx` 硬编码颜色
- 新圆角值不来自 `--radius-*`（含 7 / 12）
- 新增第四种页面外壳，或在页面里写 `max-width` / 左右 padding
- 新增卡片体系（`.xxx-card`）或第二种 tab 外观
- 用 `↻` / `▦` / `☰` / `←` / `×` / `✕` 字符代替图标
- 三层以上“卡片套卡片”
- 每行 4 个以上并列按钮
- 9px 中文正文
- 页面标题 18 / 22 / 26 混用
- 使用 solid 灰边框分隔暗色模块
- 空态只写“暂无数据”
- 用 3 秒 toast 承载报错（错误必须常驻、可复制；见 §4「反馈：toast 与报错」）
- 区域头叠两行 chrome（工具栏 + 标签栏）
- 在标签页 / 图标旁 / 区域头 / 页头标题后面挂计数（`智能体会话 5`、`会话历史 tab 上的 5`）
- 用彩色 pill / 徽标球 / 红点表「有多少」；把 `0` 也渲染出来
- 同一个动作放两个常驻入口（按钮 + 菜单都算常驻）
- 在区域头里再写一遍区域名（`Terminal` / `Chat`）
- 把报错文本 `ellipsis` 截断，不给人看完整信息
- 在亮色/暗色其中一边单独打补丁，另一边不检查
