## Bundled Agent runtime

Release builds may include the `dsh` single-file runtime downloaded from the PyPI package **`deepseek-harness-runtime-bin`** (project: [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)), which is licensed under **MIT**.

- The runtime is downloaded at build time (`npm run bundle:dsh`); it is not committed to this repository.
- Version/build metadata is recorded in `resources/dsh/manifest.json` in release builds.
- `dsh-rg` / `dsh-spawn-helper` are part of the same runtime distribution.
